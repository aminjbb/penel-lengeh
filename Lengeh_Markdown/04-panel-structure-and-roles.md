# ۴ معماری اطلاعات و نقش‌های پنل

| منوی پنل مدیریت | زیرصفحه‌های موردنیاز |
| --- | --- |
| داشبورد | فروش، سفارش نیازمند اقدام، پرداخت نامشخص، موجودی کم و هشدار خطا |
| کاتالوگ | محصولات، واریانت‌ها، دسته و جنسیت، رنگ و سایز، جدول اندازه، کتابخانه رسانه |
| کالکشن و محتوا | SHIBUI و OUTSPOKEN، هیروها، Lookها، منو و فوتر، داستان برند و صفحات |
| انبار و اصالت | گردش موجودی، رزرو، اصلاح، تیراژ، سریال، شناسنامه و المثنی |
| سفارش و مالی | فهرست سفارش، جزئیات، تایم‌لاین، پرداخت‌ها، مغایرت و بازپرداخت |
| ارسال و مرجوعی | روش و محدوده ارسال، بسته‌بندی، مرسوله و رهگیری، درخواست مرجوعی و کنترل کیفیت |
| مشتری و پشتیبانی | پروفایل حداقلی، سفارش‌ها، نشانی با دسترسی محدود، رضایت و پرونده پشتیبانی |
| بازاریابی و جستجو | ویژه امروز، ترتیب دستی، تخفیف، پیشنهاد جستجو و گزارش بدون نتیجه |
| گزارش و تنظیمات | فروش و موجودی، خروجی، رویدادها، کاربران مدیر، نقش‌ها و سرویس‌ها |

| نقش | اختیار پیشنهادی و محدودیت |
| --- | --- |
| مالک یا مدیر کل | تنظیمات و نقش‌ها و تأیید مالی؛ احراز هویت تقویت‌شده |
| اپراتور کاتالوگ | محصول و رسانه؛ بدون دسترسی مالی و نشانی کامل مشتری |
| سردبیر محتوا | کالکشن و صفحات و انتشار؛ بدون تغییر موجودی |
| انبار و ارسال | موجودی، برداشت و بسته‌بندی و رهگیری؛ بدون بازپرداخت |
| پشتیبانی | سفارش و مرجوعی و ثبت درخواست؛ بدون تأیید نهایی بازپرداخت |
| مالی | تطبیق و اجرای بازپرداخت مجاز؛ بدون مدیریت نقش |
| تحلیلگر | گزارش فقط‌خواندنی با داده شخصی پوشانده‌شده |

حساب مشتری مسیر جدا دارد: پروفایل، نشانی‌ها، سفارش‌ها و رهگیری، علاقه‌مندی، کمد لباس، رضایت اطلاع‌رسانی و اصالت قطعات خریداری‌شده. این صفحات پس از ورود مشاهده نشدند و به‌عنوان نیازمندی پیشنهادی تعریف می‌شوند. خرید مهمان یا اجبار ورود باید در S0 انتخاب شود.
