## راهنمای استفاده

ابتدا PRD و ساختار پنل و سپس اپیک‌ها و برنامه اسپرینت را مرور کنید. شناسه داستان‌ها با برنامه اسپرینت تطبیق دارد. برنامه ۲۱ هفته‌ای برآورد مبتنی بر ظرفیت مفروض است. موارد مشاهده‌شده از نیازمندی‌های پیشنهادی در متن جدا شده‌اند. بخش‌های پشت ورود و تأیید نهایی پرداخت بررسی نشده‌اند.
