# 5 اپیک E01 زیرساخت پنل و کنترل دسترسی

مبنا: O07 و نیاز عملیاتی مدیریت   |   اولویت: P0

نتیجه: اسکلت مشترک و کنترل سمت سرور برای همه ماژول‌ها   |   وابستگی: بدون وابستگی

## E01-01 ورود امن مدیر

به‌عنوان مدیر، ورود و خروج امن و مدیریت نشست می‌خواهم.  برآورد نسبی: 5 امتیاز.

معیار پذیرش: اعتبارسنجی سمت سرور؛ محدودیت تلاش؛ انقضای نشست و خروج همه نشست‌ها؛ ورود تقویت‌شده مدیر مالی و مالک.

## E01-02 نقش و مجوز

به‌عنوان مالک، مجوز مشاهده و ایجاد و ویرایش و تأیید هر حوزه را تعیین می‌کنم.  برآورد نسبی: 5 امتیاز.

معیار پذیرش: دسترسی مستقیم به API نیز کنترل شود؛ آزمون نقش غیرمجاز پاسخ ممنوع بگیرد؛ نقش محتوا نتواند بازپرداخت کند.

## E01-03 زیرساخت و ثبت تغییرات

به‌عنوان تیم، محیط آزمون، مهاجرت داده و ثبت رویداد پایدار می‌خواهم.  برآورد نسبی: 8 امتیاز.

معیار پذیرش: محیط تست از اصلی جدا؛ عامل، زمان، قبل و بعد برای تغییر حساس؛ کلید سرویس در کد مرورگر نباشد؛ نسخه مهاجرت و بازگشت آزموده شود.

## E01-04 قالب پنل و فهرست استاندارد

به‌عنوان اپراتور، جستجو، فیلتر، صفحه‌بندی و حالت خالی یکسان می‌خواهم.  برآورد نسبی: 3 امتیاز.

معیار پذیرش: RTL، صفحه‌کلید، بارگذاری و خطا؛ فیلتر در URL؛ اقدام گروهی فقط برای نقش مجاز و با پیش‌نمایش نتیجه.

تعریف پایان اپیک: رفتار پنل و سایت به یک منبع داده متصل، مجوزها و خطاها آزموده، رویدادهای حساس ثبت و سناریوی نمایشی توسط مالک محصول پذیرفته شده باشد.
